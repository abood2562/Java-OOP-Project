PROJECT 1 - STUDENT REGISTRATION AND MARKS

Files
Java_Project_Group_Report.pdf: completed group report.
Java_Project_Source.zip: six Java source files under src/project1.
Java_Project.jar: runnable application compiled for Java 17 or newer.

Run from a terminal in this folder:
java -jar Java_Project.jar

Build from source after extracting Java_Project_Source.zip:
javac --release 17 -encoding UTF-8 -d bin src/project1/*.java
java -cp bin project1.Main

VS Code: open the extracted source folder, open src/project1/Main.java, and use Run Java. A JDK and Java extensions are required.

The program is a console application. Enter numeric menu choices and follow the prompts. Data is kept in memory until exit.

Submission: the report contains attachment filenames. If your instructor requires web links and QR codes, upload the source ZIP and JAR to your sharing account and add accessible URLs. No public links have been created.

The group reported approximately two days of work; exact hours were not recorded. Names are English transliterations of the supplied Arabic names. Instructor evaluation fields are intentionally blank.
